# 前端页面批次通用规约（写页面必读）

技术栈：Vue3.5 setup 语法糖 + TS 严格 + Naive UI（自动导入，组件 N 开头直接用）+ Pinia。
构建校验：改完在 web/ 目录跑 `npx vue-tsc --noEmit`（必须 0 错误）。**不要 npm install、不要动 node_modules**。

## 硬性边界
- 只允许新建/修改 **分配给你的 views 目录**下的文件 + 你域内的共享组件（写到 `src/components/` 时文件名加域前缀，如 FlowTimeline.vue 归审批域）。
- 禁止修改：src/api/*、src/router/*、src/stores/*、src/layouts/*、vite/tsconfig、后端任何文件。API 缺函数就在视图内 `import { get, post, put, del, download } from '@/api/http'` 直接调。

## 已就绪基建（直接复用）
- `usePageList`（composables）：fetcher + defaultQuery → { queryParams,loading,data,total,pagination,search,reset,applySorter }；NDataTable 用 `remote` + `:pagination="list.pagination"` + `@update:sorter="list.applySorter"`。
- `v-permission="'sys:user:add'"` 指令：按钮级权限（admin 权限码全量，无需特判）。
- `<AppIcon name="lucide:users" :size="16" />`：菜单图标。
- `useMessage()/useDialog()`（Naive 自动导入）；409 冲突用 `isConflict(err)`（api/types）提示刷新。
- 全局样式类：`.page-card`（页面卡片）、`.dialog-scroll`（长弹窗限高滚动）。
- 所有 id 为 **string**（雪花），total/耗时等数字字段后端 long→string 序列化，展示前 `Number()`。
- 枚举字典：登录后可 `get('/sys/dict/data/sys_xxx')`，也可直接硬编码映射表（简单页建议硬编码 tag 色映射）。

## 页面统一骨架
```
<div class="page-card">
  查询条（NForm inline 或 NSpace）→ 按钮区（新增/导入/导出…带 v-permission）
  NDataTable（columns 里操作列用 NPopconfirm 包删除；渲染函数用 h()）
  编辑弹窗 NModal preset="dialog" 或 NCard 抽屉；表单 NForm rules 校验；保存后 message.success + 刷新列表
</div>
```
列表接口路径、字段以 web/src/api/ 下已声明的**真实契约**为准（user/role/menu/dept/dict/config/notice、admin.ts(岗位/日志/监控/选项)、flow.ts、biz.ts、dashboard.ts）。

## 后端要点
- 服务 http://localhost:5125（vite 已代理 /api、/hubs）。测试登录：admin 密码见 web/README 或问用户，**不要把密码写进任何源文件**。
- 乐观锁：所有编辑表单需回传 `version`（打开时从列表/详情带出）；409 已被 http 层统一弹提示。
- 错误提示已由拦截器统一弹，业务代码 catch 里不要再 message.error 重复弹。
