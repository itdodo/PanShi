## 二、技术栈

| 层 | 选型 | 关键点 |
|---|---|---|
| 后端 | .NET 10 + SqlSugarCore 5.1.4.221 + PostgreSQL 17 | CodeFirst；列名 snake_case；`Npgsql.EnableLegacyTimestampBehavior` |
| ID | Yitter 雪花（WorkerId 0-63，位宽 6） | DTO 一律字符串（LongToStringConverter 全局） |
| 认证 | JWT(2h) + RefreshToken(7天轮换) + sys_user_session | OnTokenValidated 查会话表 → 踢线/停用即时生效 |
| 任务 | Hangfire + Hangfire.PostgreSql | 三内置作业，Dashboard=/hangfire（仅 Development） |
| 实时 | SignalR `/hubs/notify` | notice / force-logout；vite 代理 ws:true |
| 前端 | Vue3.5 + TS 严格 + **Naive UI 2.4x** + Pinia3 + Vite | 按需自动引入；图标 iconify **lucide**（菜单 icon 存 `lucide:xxx`） |
| 富文本 | 公告正文入库服务端净化（script/iframe/on* 剥离）+ 前端渲染侧 DOMPurify 二次净化 | 编辑器为 wangEditor 5（`components/RichTextEditor.vue`，公告新增/编辑与小铃铛详情在用） |

## 三、数据库（28 表）

全表继承 `BaseEntity`：`id`(bigint 雪花)/`create_time`/`create_by`/`update_time`/`update_by`/`is_deleted`/`version`。
软删除全局过滤器**逐实体类型注册**（SqlSugar 泛型过滤器对抽象基类不生效——见踩坑对照）。

sys_user / sys_role / sys_menu / sys_user_role / sys_role_menu / sys_role_dept / sys_user_position / sys_position / sys_dept / sys_user_session / sys_dict_type / sys_dict_data / sys_config / sys_notice / sys_message / sys_operation_log / sys_login_log / sys_change_log / sys_file / sys_flow_definition / sys_flow_instance / sys_flow_task / sys_flow_record / sys_flow_cc / sys_flow_binding / sys_db_migration(非 BaseEntity) / biz_expense / biz_purchase_request。

唯一约束=**过滤索引**（`WHERE is_deleted=false`），由迁移脚本 `db/migrations/0001_init_indexes.sql` 建立（内嵌资源，`sys_db_migration` 记账，幂等，禁改历史）。种子固定小整数 Id（1=admin、20=admin 角色、100 起菜单树=81 条含哨兵 `__seed_v1__`）。

## 四、核心机制落点速查

| 机制 | 位置 |
|---|---|
| 雪花双通道填充 | `SqlSugarSetup.DataExecuting`（单条）+ `SqlSugarRepository.InsertRangeAsync`/`DbSeeder`（显式） |
| 乐观锁 | `SqlSugarRepository.UpdateWithVersionCheckAsync` 单条 SQL `SET …,version=version+1 WHERE id AND version`（参数带显式 DbType，PG null 防 42804） |
| 字段审计 | `UpdateWithAuditAsync` = 乐观锁 + `AuditDiff` 反射 diff → sys_change_log（冲突/无差异不落） |
| 认证/会话 | `Service/Sys/AuthService`；防爆破 FailCount+LockUntil（阈值=sys_config）；互踢+force-logout；密码有效期 mustChangePassword |
| 防提权四防护 | `UserService`（①重置 admin 拒绝 ②授予 admin 角色仅本人 ③改 admin 角色仅本人 ④停用/删除 admin 拒绝）+ `RoleService.GuardAdminRole` |
| 权限 | `[HasPermission]`→`perm:` 动态策略（`Api/Authorization`）+ `PermissionService`（版本整体失效）；数据权限 `DataScopeService` 五档表达式（预解析常量，红线 #1 合规） |
| 审批引擎 | `Service/Sys/FlowEngineService`（九大语义）+ `ConditionEvaluator`/`FlowGraphValidator`；回调 `IFlowBusinessHandler` 按 BusinessTable（AddScoped 多实现） |
| 审计三件套 | 操作日志 `OperationLogFilter`（ActionArguments+词根脱敏）；登录日志 AuthService；变更日志见上 |
| 内置作业 | `Api/Jobs/SystemJobs.cs`：sys.log.cleanup(0 2)/sys.backup.daily(0 3, pg_dump -Fc + uploads 镜像 + 保留期, 失败站内信)/sys.notice.publish(* * * * *)；`JobManagementService` 支撑监控页 |
| 安全 | 密码 PBKDF2+SHA256 兼容；上传白名单+大小+魔数；`[NoRepeatSubmit]` 2s 幂等窗；JWT 密钥启动校验 ≥32 字符；登录/验证码限流（RateLimit:LoginPermit 可配） |

## 五、API 一览（/api/v1，统一 {code,msg,data}，401/403/409 同形）

- `/auth` login refresh logout profile(GET/PUT) change-password captcha avatar sessions(+/DELETE :id)
- `/sys/user` page options {id} POST PUT DELETE {id}/password/reset {id}/roles import-template import export
- `/sys/role` page list {id} POST PUT DELETE {id}/menus export；`/sys/menu` tree tree/my options POST PUT DELETE
- `/sys/dept` tree options POST PUT DELETE；`/sys/position` page list POST PUT DELETE
- `/sys/dict` type/page type/list data/{code} data/type/{id} type POST PUT DELETE + data POST PUT DELETE
- `/sys/config` page POST PUT DELETE；`/sys/notice` page latest {id} POST PUT DELETE
- `/sys/message` send my/page my/unread-count my/{id}/read read-all
- `/sys/log` operation(+export / DELETE cleanup) login(…) change(+DELETE cleanup)
- `/sys/flow` def(CRUD+enable+categories+versions) binding(GET/PUT/DELETE) task(todo/done/todo-count/{id}/act|return|transfer|addsign) submit instance(page/my/{id}/by-business/{id}/withdraw|void) cc-me(+read)
- `/biz/expense`、`/biz/purchase` page {id} POST PUT DELETE {id}/submit
- `/file` upload {id} {id}/download；`/dashboard/stats`；`/monitor` jobs(+trigger/toggle) online(+DELETE kick) server；`/health`

## 八、运行与部署

```bash
docker compose up -d              # panshi-db + panshi-api（主机 18080，含前端）
bash scripts/verify.sh          # 提交前验收：编译/两套测试/类型检查/构建
# 开发：docker compose up -d panshi-db
dotnet run --project src/Panshi.Api    # http://localhost:5125，/swagger /hangfire(Dev)
cd web && npm install && npm run dev    # 5173，代理 /api /hubs
```
**必改**：`Jwt__SecretKey`、compose 中 SA 等价密码（POSTGRES_PASSWORD 与连接串同步）。备份卷 `./backups` api/db 共享。反向代理 `/hubs` 需 WebSocket 转发、`/api/v1/file/*/download` 暴露头 `Content-Disposition`。
初始账号见 `DbSeeder.SeedOrg`（内置管理员，首次登录后立即改密）。
